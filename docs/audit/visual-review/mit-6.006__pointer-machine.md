## 版面
单幅横版结构，共三层：顶部一行居中标题；中部一行两列，左为浅蓝圆角矩形、右为浅紫圆角矩形，两框之间垂直排列两条短水平箭头，上条箭头头朝左（由右框指向左框方向），下条箭头头朝右（由左框指向右框方向），分别与框内第二行（prev）和第三行（next）的高度对齐；底部一行居中注释文字。每个框内各三行字段文字，水平居中。

## 全部文字
指针机：动态对象、常数个字段，字段是字或引用
val = 5
prev = null
next = 引用
val = -1
prev = 引用
next = null
两条箭头与字段行一一对应：对着 prev 行的那条朝左，对着 next 行的那条朝右

## 缺陷
未发现。逐条核对：框内文字均居中且与框线留有裕量，未见碰线或溢出；两框顶底边目测齐平、宽度相近（定性估计，未量坐标）；上箭头对齐 prev 行且朝左、下箭头对齐 next 行且朝右，与底部注释描述一致；语义上左框 next = 引用 对应朝右指向右框、右框 prev = 引用 对应朝左指向左框，而左 prev = null、右 next = null 不配箭头，与链表头尾含义自洽，无数字或方向矛盾；注释已说明箭头与字段行的对应规则，未丢失必要信息。

箭头方向、行对齐与字段语义（next 朝右、prev 朝左、null 无箭头）完全自洽，版面干净无溢出或错位。
