## 版面
单幅横向版面，自上而下三层：顶部一行居中标题；中部为一行两列的两个圆角矩形框（左为浅蓝框、右为浅紫框），两框之间的窄隙内上下叠放两条水平单向箭头，上面一条朝左、下面一条朝右；底部一行居中的灰色注释文字。除这两条箭头外无其他连线或走向。

## 全部文字
指针机：动态对象、常数个字段，字段是字或引用
val = 5
prev = null
next = 引用
val = -1
prev = 引用
next = null
两条箭头与字段行一一对应：对着 prev 行的那条朝左，对着 next 行的那条朝右

## 缺陷
- 对齐错位：中间两条箭头未与注释所称的字段行精确水平对齐。朝左的上箭头垂直中心比两框的 prev 行文字中心偏高约半字高，视觉上悬在 val 行与 prev 行之间偏下；朝右的下箭头也比 next 行文字中心偏高约四分之一字高。与底部注释"一一对应"的表述相比精度不足。
- 其余方面：文字均未与框线或箭头相碰、未溢出方框；两框大小与行距一致、对齐良好；箭头数量（两条）、方向（上左下右）与注释描述一致；左框 next = 引用 配朝右箭头、右框 prev = 引用 配朝左箭头、两个 null 字段不配箭头，引用语义自洽，未发现数字、顺序或结论上的矛盾。

## 判定
箭头与 prev、next 两行的垂直对齐有轻微偏差，只需微调箭头纵坐标即可，图意与引用关系本身没有错误。
